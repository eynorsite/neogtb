## 2023-10-25 - Improve Newsletter Async Form UX & Accessibility
**Learning:** When using Alpine.js for background form submissions without page reloads, conditionally rendering success/error messages can cause screen readers to miss them. Using `aria-live="polite"` with `role="status"` for success messages, and `role="alert"` for error messages, ensures they are read aloud.
**Action:** When creating asynchronous form submissions (like newsletter or contact forms), always use `role="status"`/`aria-live="polite"` for non-disruptive feedback (like success) and `role="alert"` for critical feedback (like validation errors). Additionally, replacing generic text ("...") with a spinner containing a hidden `sr-only` descriptive text improves both visual and screen reader accessibility.
