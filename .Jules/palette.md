## 2025-06-25 - Alpine.js Accordion Accessibility Patterns
**Learning:** Found widespread inconsistency in Alpine.js accordions across the app. Some had partial ARIA support (like `aria-expanded` manually evaluated) but lacked semantic connections (`aria-controls`) and almost all lacked explicit keyboard focus indicators (`focus-visible`). Relying on default browser outlines for interactive elements is insufficient for clear keyboard navigation in a custom styled app.
**Action:** Always enforce a complete accessibility trio for interactive disclosures: `type="button"`, dynamic `:aria-expanded="state ? 'true' : 'false'"`, and explicit `aria-controls="id"`. For styling, standardize on Tailwind's `focus:outline-none focus-visible:ring-2 focus-visible:ring-accent-500 rounded` for interactive triggers.
