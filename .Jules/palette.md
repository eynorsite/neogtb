## 2024-06-14 - Alpine.js Accordion Accessibility\n**Learning:** The FAQ accordions lacked proper ARIA attributes (aria-expanded, aria-controls) and visible focus states for keyboard navigation. Alpine.js state can be easily bound to ARIA attributes using `:aria-expanded="open.toString()"`.\n**Action:** Always include `type="button"`, `:aria-expanded`, `aria-controls`, and Tailwind `focus-visible:` utility classes on interactive disclosure components.
