## 2024-05-24 - Dynamic Focus Rings for Custom Branded Components
**Learning:** When building UI components that allow user-defined primary colors (like a chatbot widget), default focus rings (e.g., Tailwind's `focus-visible:ring-blue-500`) can clash visually or fail accessibility contrast requirements against the custom background. If we omit focus rings entirely, keyboard accessibility is lost.
**Action:** Use a reusable pattern of setting CSS custom properties inline to dynamically theme Tailwind utilities. For example, add `:style="'background-color: ' + color + '; --tw-ring-color: ' + color"` to the element, and use `focus-visible:ring-2 focus-visible:ring-offset-2` in the class list. This guarantees that keyboard focus indicators perfectly match the brand color and maintains a high standard of accessibility without breaking design constraints.
