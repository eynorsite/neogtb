## 2024-07-04 - ARIA roles in Alpine.js dynamic feedback messages
**Learning:** When using Alpine.js (`x-if` or `x-show`) to dynamically render feedback messages (like errors or success confirmations) without a full page reload, the elements must include appropriate ARIA roles (`role="alert"` for errors, and `role="status"` with `aria-live="polite"` for non-disruptive success messages). If these roles are missing, screen readers will not announce the state changes to visually impaired users, leaving them unaware of form submission outcomes. Also, when verifying Alpine.js v3 component states programmatically via Playwright, the component data should be accessed using `Alpine.$data(document.querySelector('selector'))` rather than internal properties like `__x.$data`.
**Action:** Always ensure dynamic feedback elements injected by Alpine.js are marked with semantic ARIA roles (`role="alert"` or `role="status" aria-live="polite"`) to maintain accessibility.
